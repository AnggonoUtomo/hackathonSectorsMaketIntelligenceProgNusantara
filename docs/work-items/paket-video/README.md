dengan teks penjelas tanpa narasi suara. Status: file video selesai dan diverifikasi;
upload dan submission resmi belum dilakukan.

logo NusaLens dan data Sectors yang tersedia. Bukan slideshow konsep/fake UI.

tetap terlihat. Hindari API berbayar bila data tersimpan mencukupi.

Tidak mengubah fitur, commit/push, membeli hosting, mengunggah atau submit.

teaser satu menit publik; judging maksimal tiga menit dapat publik/unlisted;
hosting tidak wajib; repo publik, problem statement, track, anggota tim dan
social post dengan template resmi tetap diperlukan. Freeze saat submit atau
deadline 8 Oktober 2026 pukul 23.59 WIB, mana yang lebih dahulu.

Video tidak menggunakan musik atau aset pihak ketiga yang lisensinya tidak jelas.
File output di `storage/app/private/submission-videos/final/` tidak ikut Git.
