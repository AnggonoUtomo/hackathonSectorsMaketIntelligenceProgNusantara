# Checklist Penuntasan MVP

- [x] Inventaris source dan keputusan; catat otorisasi eksekusi menyeluruh.
- [ ] Probe provider terarah, catat biaya dan gap unit/periode.
- [ ] Kalkulator v1 dan pemilihan peer/periode dengan unit test.
- [ ] Adapter input real, pagination lengkap dan test cache/error/budget.
- [ ] Persistence bukti immutable dan replay.
- [ ] Cockpit nilai, bukti peer, penjelasan serta grafik Recharts.
- [ ] Compare memakai Intelligence; snapshot server-authoritative.
- [ ] Rename/delete snapshot privat dan update versi.
- [ ] Retensi bukti bersama 30 hari; salinan lengkap dalam riset privat tetap utuh.
- [ ] Dashboard/navigasi/panduan dan status task aktif sinkron.
- [ ] PHPUnit, typecheck, lint, build dan browser QA.

Item dicentang berdasarkan bukti, bukan persetujuan atau perkiraan.
