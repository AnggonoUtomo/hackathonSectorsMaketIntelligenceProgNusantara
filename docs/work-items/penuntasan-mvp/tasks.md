# Checklist Penuntasan MVP

- [x] Inventaris source dan keputusan; catat otorisasi eksekusi menyeluruh.
- [x] Probe provider terarah, catat biaya dan gap unit/periode.
- [x] Kalkulator v1 dan pemilihan peer/periode dengan unit test.
- [x] Adapter input real, pagination lengkap dan test cache/error/budget.
- [x] Persistence bukti immutable dan replay.
- [x] Cockpit nilai, bukti peer, penjelasan serta grafik Recharts.
- [x] Compare memakai Intelligence; snapshot server-authoritative.
- [x] Rename/delete snapshot privat dan update versi.
- [x] Retensi bukti bersama 30 hari; salinan lengkap dalam riset privat tetap utuh.
- [x] Dashboard/navigasi/panduan dan status task aktif sinkron.
- [x] PHPUnit, typecheck, lint, build dan browser QA.
- [x] Regresi awal tahun: periksa tahun laporan terbaru sebelum fallback, tanpa cutoff Mei.

## Di luar penutupan implementasi lokal

- [ ] Validasi sumber adjusted close, kalender dan smoke valuasi penuh.
- [ ] Review pemahaman pengguna atas bukti/kelengkapan.
- [ ] Deployment publik, email produksi, scheduler, video dan submission.

Item tersebut tidak dianggap selesai oleh test fixture atau push repository.

Item dicentang berdasarkan bukti, bukan persetujuan atau perkiraan.
